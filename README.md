# VioScore

A professional three-page site about credit scoring with alternative data for finance.
All datasets shown are illustrative and synthetic. The site makes no claim of being validated or regulated.
Static HTML, CSS and JavaScript. No build step. Original SVG art is allowed; no external images.

## Pages
- `index.html`: Home
- `pages/how-it-works.html`: How it works
- `pages/datasets.html`: Datasets

## Layout
- `css/tokens.css`: design tokens (Designer)
- `css/layout.css`: page shell layout (UI/UX)
- `css/site.css`: base styles
- `js/nav.js`: menu behaviour
- `js/app.js`: page behaviour
- `assets/`: original SVG art
